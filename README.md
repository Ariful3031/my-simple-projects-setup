# Brainloom online learning platform

Brainloom nline learning platform is a responsive web app built with React, Express, MongoDB, and Tailwind CSS, allowing users to browse, filter, and manage property listings securely with login/register functionality. It features category-based search, detailed property information, profile management, and is deployed on Vercel for a seamless experience.

## Features

- **User Authentication**: Secure user authentication system with login/register functionality.
- **Properties Listings**: Browse through a wide range of flat listings with detailed information about location, price, and amenities.
- **Search and Filter**: Easily search for properties based on Title, Category more.
- **Profile Management**: Manage your profile information and preferences to find the best match.


## Technologies Used

- **Frontend**: React.js, Redux,firebase
- **Backend**: Express.js, node.js
- **Authentication**: JWT (JSON Web Tokens)
- **Database**: mongodb
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
